# 🟩 Зелёные ролики: МЭЛ ФУТАЖЭС / БУРМОЛДА.РУ

Два рекламных ролика на чистом хромакейном фоне **`#00FF00`**, полностью нарисованные кодом
(canvas 2D) и синхронизированные с двумя звуками из этого репозитория.

| Файл | Сцена | Текст звука | Длительность |
|---|---|---|---|
| **`mel-footage-1.html`** | открывается окошко браузера → вылетает стена футажей → один кадр выделяется и увеличивается → «МЭЛ ФУТАЖЭС / ОНЛАЙН» | «Забери свой лучший кадр… мэл футажэс онлайн!» | 4.15 с + 1.0 с концовки |
| **`burmolda-ru-2.html`** | футажи летают вокруг → кадр вылетает в центр → «БУРМОЛДА» → адресная строка «бурмолда.ру» | «…найди свою бурмолду… бурмолда точка ру» | 3.79 с + 1.0 с концовки |

`index.html` — стартовая страница со ссылками на оба ролика.

Каждый HTML **автономный**: внутри звук (base64), фото футажей, шрифты (Russo One + Montserrat),
движок и сцена. Интернет не нужен, открывается двойным кликом.

---

## Как пользоваться

1. Открыть `mel-footage-1.html` (или `burmolda-ru-2.html`) в Chrome / Edge.
2. Выбрать формат: **9:16** (Reels, Shorts, TikTok), **1:1** (пост) или **16:9** (YouTube).
3. Выбрать качество: 720p / 1080p / 1440p.
4. Нажать **«⏺ Записать видео»** — ролик рендерится в реальном времени и скачивается
   файлом **MP4** (если браузер умеет) или **WEBM**, со звуком.
5. В редакторе положить ролик поверх геймплея и вырезать зелёный.

Хоткеи: **Space** — плей/пауза, **R** — заново, **S** — сохранить PNG-кадр.

### Настройки хромакея

| Программа | Что делать |
|---|---|
| Premiere Pro | Effects → **Ultra Key**, Key Color → пипеткой по фону, Tolerance 35–45 % |
| DaVinci Resolve | **3D Keyer** / **Delta Keyer**, color pick `#00FF00` |
| CapCut | «Хромакей» → выбрать зелёный, интенсивность 40–60 |
| OBS | Источник «Окно браузера» + фильтр **Хромакей**, Key Color → `00FF00` |

Графика рисуется плотными цветами без зелёных оттенков; полупрозрачные заливки поверх фона
не используются, поэтому ключ снимается чисто, без зелёной каймы.

## Как поменять текст / фото / тайминги

Слова — в блоке `CFG` в начале каждой сцены:

```js
const CFG = {
  lines: ['ЗАБЕРИ СВОЙ', 'ЛУЧШИЙ КАДР'],  // верхние строки
  brand: 'МЭЛ ФУТАЖЭС',                   // крупное слово
  brand2: 'ОНЛАЙН',                       // плашка
  url: 'mel-footage.online',
  cta: 'ЗАЛЕТАЙ НА МЭЛ ФУТАЖЭС',
  ctaSub: 'ССЫЛКА В ОПИСАНИИ',
  ticker: '...'                           // бегущая строка
};
```

Тайминги фраз — рядом в `T` (`l1`, `l2`, `pick`/`lock`, `brand`/`domain`, `cta`). Они выставлены
по анализу громкости конкретных mp3 (фразы: 0.10–1.74 / 2.06–3.00 / 3.24–3.80 в первом файле).

**Фото** лежат в `src/photos/` (5 квадратных превью 256×256). Заменить — просто положить свои
jpg/png с теми же именами (или любыми другими — сборка берёт все файлы папки) и пересобрать.

## Структура проекта

```
mel-footage-1.html      ← готовый ролик №1 (сборка, править не нужно)
burmolda-ru-2.html      ← готовый ролик №2
index.html              ← страница со ссылками
build.mjs               ← сборка роликов из src/ (node build.mjs)

src/common.js           ← «кисти»: текст, плитки футажей, окно браузера, рамка выделения,
                          иконки, деньги, аудио-огибающая
src/scene-1.js          ← сцена «Мэл футажэс»
src/scene-2.js          ← сцена «Бурмолда.ру»
src/runtime.js          ← плеер, запись видео, интерфейс
src/style.css           ← оформление страницы
src/template.html       ← каркас HTML
src/photos/             ← превью для стены футажей
src/fonts/              ← Russo One, Montserrat (OFL)
```

Пересобрать после правок:

```bash
node build.mjs
```

Зависимостей нет — только Node.js. Сборка сама проверяет синтаксис сцен и то, что все `id`,
которые ищет рантайм, есть в шаблоне.

## Как это работает

* **Звук** декодируется Web Audio в буфер, из него считается огибающая громкости (200 Гц).
  Она подмешивается в анимацию: тряска кадра, «пульс» текста и плиток — картинка дышит вместе с голосом.
* **Анимация** — чистая функция времени `draw(t)`: любой момент можно отрендерить отдельно
  (это же используется для слайдера и PNG-кадров).
* **Запись** — `canvas.captureStream(60)` + аудиодорожка через `MediaStreamAudioDestinationNode`
  в `MediaRecorder`. Длительность и синхрон держатся на часах AudioContext.

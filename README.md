# 🟩 Зелёные ролики: MELLFOOTAGES.ONLINE / BURMOLDA.RU

Два рекламных ролика на чистом хромакейном фоне **`#00FF00`**, полностью нарисованные кодом
(canvas 2D) и синхронизированные с двумя звуками из этого репозитория.

Главный элемент — **чёрное окно сайта** (тёмный интерфейс, адресная строка, сетка футажей).
При наложении на геймплей оно читается как отдельная плашка и ни с чем не сливается.

| Файл | Звук | Сцена | Длительность |
|---|---|---|---|
| **`mellfootages-online.html`** | `[Меллстрой]_рифм......нлайн.mp3` — «Забери свой лучший кадр… мэл футажэс онлайн!» | окно `mellfootages.online`: сетка футажей → курсор открывает кадр → превью «Скачать кадр» → плашка «МЭЛ ФУТАЖЭС» + домен | 3.79 с + 1.0 с концовки |
| **`burmolda-ru.html`** | `[Меллстрой]_рифм......а ру .mp3` — «…найди свою бурмолду… бурмолда точка ру» | окно `burmolda.ru`: в поиске печатается «найди свою бурмолду» → кадр находится → превью → подсветка адресной строки + домен | 4.15 с + 1.0 с концовки |

`index.html` — стартовая страница со ссылками на оба ролика.

Каждый HTML **автономный**: внутри звук (base64), фото футажей, шрифты (Russo One + Montserrat),
движок и сцена. Интернет не нужен, открывается двойным кликом.

## Как пользоваться

1. Открыть `mellfootages-online.html` (или `burmolda-ru.html`) в Chrome / Edge.
2. Выбрать формат: **9:16** (Reels, Shorts, TikTok), **1:1** (пост) или **16:9** (YouTube).
3. Выбрать качество: 720p / 1080p / 1440p.
4. Нажать **«⏺ Записать видео»** — ролик рендерится в реальном времени и скачивается
   файлом **MP4** (если браузер умеет) или **WEBM**, со звуком.
5. В редакторе положить ролик поверх геймплея и вырезать зелёный.

Хоткеи: **Space** — плей/пауза, **R** — заново, **S** — сохранить PNG-кадр.

### Настройки хромакея

| Программа | Что делать |
|---|---|
| Premiere Pro | Effects → **Ultra Key**, Key Color → пипеткой по фону, Tolerance 35–45 % |
| DaVinci Resolve | **3D Keyer** / **Delta Keyer**, color pick `#00FF00` |
| CapCut | «Хромакей» → выбрать зелёный, интенсивность 40–60 |
| OBS | Источник «Окно браузера» + фильтр **Хромакей**, Key Color → `00FF00` |

Фон заливается чистым `#00FF00`, графика — плотными цветами без зелёных оттенков,
полупрозрачных заливок поверх фона нет, поэтому ключ снимается без каймы.
Чёрное окно даёт контрастную «подложку» — нарезчику не нужно подбирать фон под ролик.

## Как поменять текст / фото / тайминги

Слова — в блоке `CFG` в начале каждой сцены:

```js
const CFG = {
  lines: ['ЗАБЕРИ СВОЙ', 'ЛУЧШИЙ КАДР'],  // верхние строки
  brand: 'МЭЛ ФУТАЖЭС',                   // крупное название
  badge: 'ОНЛАЙН',
  domain: 'mellfootages.online',
  ctaSub: 'ССЫЛКА В ОПИСАНИИ',
  ticker: '...'                           // бегущая строка
};
```

Тайминги фраз — рядом в `T` (`l1`, `l2`, `pick`/`found`, `brand`, `online`/`domain`, `cta`).
Они выставлены по анализу громкости конкретных mp3:

* `…нлайн.mp3` (3.79 с): фразы 0.14–1.44 / 1.82–3.24 / 3.24–3.78;
* `…а ру .mp3` (4.15 с): фразы 0.10–1.74 / 2.06–3.00 / 3.24–3.80.

**Фото** лежат в `src/photos/` (5 квадратных превью 256×256). Заменить — положить свои
jpg/png с любыми именами в эту папку и пересобрать.

## Структура проекта

```
mellfootages-online.html  ← готовый ролик №1 (сборка, править не нужно)
burmolda-ru.html          ← готовый ролик №2
index.html                ← страница со ссылками
build.mjs                 ← сборка роликов из src/ (node build.mjs)

src/common.js             ← «кисти»: тёмное окно сайта, плитки футажей, плашка с доменом,
                            рамка выделения, курсор, текст, аудио-огибающая
src/scene-1.js            ← сцена «Мэл футажэс» (mellfootages.online)
src/scene-2.js            ← сцена «Бурмолда» (burmolda.ru)
src/runtime.js            ← плеер, запись видео, интерфейс
src/style.css             ← оформление страницы
src/template.html         ← каркас HTML
src/photos/               ← превью для сетки футажей
src/fonts/                ← Russo One, Montserrat (OFL)
```

Пересобрать после правок:

```bash
node build.mjs
```

Зависимостей нет — только Node.js. Сборка проверяет синтаксис сцен и то, что все `id`,
которые ищет рантайм, есть в шаблоне.

## Как это работает

* **Звук** декодируется Web Audio в буфер, из него считается огибающая громкости (200 Гц).
  Она подмешивается в анимацию: тряска кадра, «пульс» окна и кнопок.
* **Анимация** — чистая функция времени `draw(t)`: любой момент можно отрендерить отдельно
  (это же используется для слайдера и PNG-кадров).
* **Запись** — `canvas.captureStream(60)` + аудиодорожка через `MediaStreamAudioDestinationNode`
  в `MediaRecorder`. Длительность и синхрон держатся на часах AudioContext.

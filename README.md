# 🟩 Зелёные ролики: АПГРЕЙДЕР / МУСОРДРОП / РУБАП

Два рекламных ролика на чистом хромакейном фоне **`#00FF00`**, полностью нарисованные кодом
(canvas 2D) и синхронизированные с двумя звуками Меллстроя из этого репозитория.

| Файл | Сцена | Звук | Длительность |
|---|---|---|---|
| **`upgrader-rubap-1.html`** | Апгрейд-колесо → мусор в бак → золотой АК → РУБАП | `[Меллстрой]_рифм......а ру .mp3` | 4.15 с + 1.0 с концовки |
| **`upgrader-rubap-2.html`** | Слот-машина → барабаны встают → джекпот x1000 | `[Меллстрой]_рифм......нлайн.mp3` | 3.79 с + 1.0 с концовки |

`index.html` — стартовая страница со ссылками на оба ролика.

Каждый HTML **автономный**: внутри лежат звук (base64), шрифты (Russo One + Montserrat),
движок и сцена. Интернет не нужен, можно открывать двойным кликом с диска.

---

## Как пользоваться

1. Открыть `upgrader-rubap-1.html` (или `-2`) в Chrome / Edge.
2. Выбрать формат: **9:16** (Reels, Shorts, TikTok), **1:1** (пост) или **16:9** (YouTube).
3. Выбрать качество: 720p / 1080p / 1440p.
4. Нажать **«⏺ Записать видео»** — ролик рендерится в реальном времени и скачивается
   файлом **MP4** (если браузер умеет) или **WEBM**, со звуком.
5. В редакторе положить ролик поверх геймплея и вырезать зелёный.

Хоткеи: **Space** — плей/пауза, **R** — заново, **S** — сохранить PNG-кадр.

### Настройки хромакея

| Программа | Что делать |
|---|---|
| Premiere Pro | Effects → **Ultra Key**, Key Color → пипеткой по фону, Tolerance 35–45 % |
| DaVinci Resolve | **3D Keyer** / **Delta Keyer**, color pick `#00FF00` |
| CapCut | «Хромакей» → выбрать зелёный, интенсивность 40–60 |
| OBS | Источник «Окно браузера» + фильтр **Хромакей**, Key Color → `00FF00` |

Графика нарисована плотными цветами без зелёных оттенков и без «полупрозрачных» заливок
поверх фона, поэтому ключ снимается чисто, без зелёной каймы.

## Как поменять текст / тайминги

В начале каждой сцены есть блок `CFG`:

```js
const CFG = {
  word1: 'АПГРЕЙДЕР',   // первая надпись (по первой фразе звука)
  word2: 'МУСОРДРОП',   // вторая
  word3: 'РУБАП',       // третья
  cta: 'ЗАЛЕТАЙ НА АПГРЕЙДЕР',
  ctaSub: 'ССЫЛКА В ОПИСАНИИ',
  ...
};
```

Тайминги фраз лежат рядом в `T` (`b1`, `b2`, `b3`, `cta`) — они выставлены по анализу
громкости конкретных mp3 (фразы на 0.15–1.7 с, 2.06–3.0 с, 3.24–3.8 с в первом файле).
Меняешь звук → поправь эти четыре числа.

## Структура проекта

```
upgrader-rubap-1.html   ← готовый ролик №1 (трогать не нужно, это сборка)
upgrader-rubap-2.html   ← готовый ролик №2
index.html              ← страница со ссылками
build.mjs               ← сборка роликов из src/ (node build.mjs)

src/common.js           ← «кисти»: текст, иконки мусора и скинов, деньги, колесо, аудио-огибающая
src/scene-1.js          ← сцена «Апгрейдер»
src/scene-2.js          ← сцена «Слот / Рубап»
src/runtime.js          ← плеер, запись видео, интерфейс
src/style.css           ← оформление страницы
src/template.html       ← каркас HTML
src/fonts/              ← Russo One, Montserrat (OFL)
```

Пересобрать после правок:

```bash
node build.mjs
```

Зависимостей нет — только Node.js.

## Как это работает

* **Звук** декодируется Web Audio в буфер; из него считается огибающая громкости (200 Гц).
  Она подмешивается в анимацию: тряска кадра, «пульс» текста, скорость колеса — поэтому
  картинка дышит вместе с голосом без ручной подгонки.
* **Анимация** — чистая функция времени `draw(t)`, без накопления состояния: любой момент
  можно отрендерить отдельно (это же используется для слайдера и PNG-кадров).
* **Запись** — `canvas.captureStream(60)` + аудиодорожка через `MediaStreamAudioDestinationNode`
  в `MediaRecorder`. Длительность и синхрон гарантируются часами AudioContext.

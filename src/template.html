Как снять ролик:
  1. Жми «Записать видео» — файл (MP4 или WEBM) скачается сам.
  2. В редакторе (Premiere, CapCut, DaVinci, OBS) клади его поверх геймплея.
  3. Хромакей: ключевой цвет #00FF00, RGB 0 · 255 · 0, допуск 30–45 %.
  4. В OBS: источник «Окно браузера» + фильтр «Хромакей», цвет Key Color → 00FF00.

Клавиши: Space — плей/пауза, R — заново, S — кадр PNG.

Звук и графика лежат внутри этого файла — интернет не нужен. Ролик рендерится кодом на canvas в реальном времени.

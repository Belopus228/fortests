Как снять видео

  1. Открой ролик, выбери формат (9:16 / 1:1 / 16:9) и качество.
  2. Жми «Записать видео» — файл MP4 (или WEBM) скачается сам, звук уже внутри.
  3. Кинь ролик поверх геймплея в Premiere / CapCut / DaVinci / OBS.
  4. Хромакей: ключевой цвет #00FF00 (RGB 0 · 255 · 0), допуск 30–45 %.
